# Справочник по JavaScript API плагинов MelowGram

## Метаданные плагина
Метаданные объявляются в начале файла плагина:

```js
const title = "Мой Плагин";
const description = "Подробное описание плагина";
const version = "1.0.0";
const author = "Name";
const author_link = "@inlokr"; // ссылка на канал/профиль (например, @inlokr или https://t.me/inlokr)
const icon = "myicon.svg";     // .svg или .png (20x20) из папки plugins
```

## Кнопка «FAQ» (вопросик)
В меню настроек `MelowGram -> Plugins` слева от переключателя каждого плагина расположена кнопка с иконкой вопроса. При нажатии на неё открывается окно с подробной информацией о плагине:
- **Version**: версия плагина
- **Author**: автор (кликабельная плашка, при нажатии открывает `author_link` в Telegram/браузере)
- **Description**: описание функционала плагина
